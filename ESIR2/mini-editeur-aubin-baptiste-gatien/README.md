Mini-Éditeur de texte

Ce projet contient la conception et le code d’un mini-éditeur de texte réalisé en Java.
Il permet de sélectionner, copier, couper, coller et insérer du texte dans une zone de travail.

Contenu du projet

src/Commandes/ : contient les classes des différentes commandes (Copy, Cut, Paste, Insert, Select).

src/principales/ : contient les classes principales du programme comme Buffer, Recorder, UndoManager et Main.

Main.java : lance l’application et gère les boutons de l’interface.

diagrammes/ : regroupe les diagrammes UML (cas d’utilisation, classes, séquences).

rapport/ : contient le dossier de conception et le dossier développeur.

Fonctionnalités

Version 1 : sélection, insertion, copie, coupe, collage.

Version 2 : ajout de l’historique (undo/redo) et du système d’enregistrement des actions.
